# 非均匀长 IR 卷积：实现与性能记录

2026-10-10。以 `c9cb522` 的均匀分区实现为对照，加入一个有界调度的晚期
分区。最终只对 **双声道、每声道 IR 至少 65536 taps** 启用；其余情况保留
原有均匀分区。完整 IR、零外部算法延迟和 `IR 长度 − 1` 帧尾部不变。

## 已采用范围的结果

同一进程、同一逻辑核，固定 `ABBA BAAB` 顺序，每个实现四次至少 250 ms
稳态计时；每个场景另外保留一次 4096 回调的完整分布。环境为 Windows、
i5-12500H、Rust 1.93.1、RealFFT 3.5.0 / RustFFT 6.4.1。
稳态指标是 ns/输入标量样本，CPU 使用 Windows 线程内核时间加用户时间。

以下均为 **65536 taps / 双声道**，是此次机器上的观测，不代表所有 IR
长度、CPU 或设备。64 帧与 512 帧使用相同算法与滤波器。

| 指标 | 64 帧：原实现 → 新实现 | 512 帧：原实现 → 新实现 |
| --- | ---: | ---: |
| 墙钟耗时，中位数 ns/sample | 164.533 → 135.357（−17.7%） | 84.936 → 53.068（−37.5%） |
| 线程 CPU，中位数 ns/sample | 164.092 → 133.849（−18.4%） | 84.440 → 52.982（−37.3%） |
| 回调 p99，μs | 29.7 → 32.0（+2.3 μs） | 139.7 → 85.3 |
| 回调最大值，μs | 83.9 → 82.7 | 1987.7 → 308.5 |
| 保留 Rust 堆，KiB | 4341.30 → 5107.41 | 4341.30 → 5107.41 |
| 构造峰值 Rust 堆，KiB | 4357.41 → 5123.31 | 4357.41 → 5123.31 |

这是 **CPU 与内存的取舍**：保留堆增加 766.11 KiB，约 17.6%。64 帧
p99 也有小幅增加，因此不能说所有性能指标都改善。48 kHz 下，64 帧的
时间预算为 1333.33 μs；新实现观测到的 82.7 μs 最大值占约 6.2%。有限
样本的最大值不是操作系统调度或未来播放绝不超时的保证。

内存按 Rust 分配器请求字节统计，包含实例及 FFT 计划，排除调用方输入、
输出缓冲；构造峰值也包含构造期间的临时缓冲。它不是 RSS、系统提交量或
内存分配器开销。处理与 reset 的分配、释放、重分配次数均为零。

## 算法与调度

前 8192 帧 IR 保留原有 1024 帧分区及 overlap-save 头部；后续 IR 使用
4096 帧分区、8192 点实数 FFT。晚期 IR 从第 8192 帧才开始贡献输出，
因此有一个周期收集输入，再用一个周期完成运算，不增加外部延迟。

每个工作项是一个声道的正 FFT、一个分区乘加或一个声道的逆 FFT。FFT
按四个乘加工作单位安排间隔；每个 1024 帧边界前后各留 128 帧空档，避免
与早期分区的边界工作堆叠。排期只依赖源帧位置，不依赖回调次数。

所有存储在构造期分配。reset 仅使输入历史失效，不清空随 IR 长度增长
的频谱历史。干湿渐变使用现有的原始输入副本，不引入第二条整卷积路径。
`partition_size()` 仍报告基础分区 1024；`fft_size()` 报告最大变换尺寸，
启用晚期层时为 8192。短 IR 与 FIR EQ 的公开路由常量不变。

## 未采用的范围与保留的失败

最初候选 v1 的大逆 FFT 与原有边界重叠，双声道小回调 p99 回退；进行了
一次明确的调度修改得到 v2。没有重复运行未修改的候选来挑选好结果。

| v2 研究配置 | CPU 中位数变化 | 回调 p99，μs | 回调最大值，μs | 决定 |
| --- | ---: | ---: | ---: | --- |
| 32768 taps / 2ch / 64 帧 | −4.1% | 24.2 → 29.8 | 81.5 → 77.5 | p99 增加约 23%，较小 IR 保留均匀分区 |
| 32768 taps / 2ch / 512 帧 | −18.7% | 73.7 → 73.5 | 271.9 → 152.7 | 同一实例需支持小回调，不单凭本行收益启用 |
| 65536 taps / 6ch / 64 帧 | −27.8% | 155.9 → 112.7 | 790.1 → 2148.6 | 超过 1333.33 μs 回调预算，六声道不启用 |
| 65536 taps / 6ch / 512 帧 | −47.2% | 742.6 → 346.9 | 1198.2 → 1033.0 | 不据本行外推六声道小回调已通过 |

六声道 64 帧的原实现最大值也超过旧任务的 50% 时间预算目标。此次不能
宣称该实时门槛得到解决，不能未经证据把异常峰值全部归因于操作系统。
六声道候选还增加约 1657.67 KiB 保留堆。12288 taps 对照不启用晚期层，
输出完全一致，CPU 中位数相同；墙钟 +0.6%，不主张其获得加速。

## 质量与验证范围

- 保留完整 FIR 系数，没有截断 IR、减少系数精度或近似混响。
- 旧版/新版成对探针的全部七个研究配置中，最大样本绝对差约
  `1.464e-17`；已采用双声道配置最大约 `1.342e-17`。
- 新增强晚期稀疏 IR 的直接卷积参考，以及密集 IR 的独立 overlap-save
  参考，覆盖分区边界、历史环绕、非整块输入、原地/非原地处理、干湿渐变、
  中途 reset 和完整有限尾部，容差 `1e-10`。通过不要求位一致。
- 两种功能配置下原有及新增卷积相关测试均通过 57 项；最终收窄路由后，
  重新通过三项受影响测试（含 65535/65536 阈值与声道路由），并通过严格
  library Clippy 和变更文件格式检查。没有扩大到无关语料或反复跑全套基准。
